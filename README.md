# Karumathi — A Life Remembered

Undangan keluarga digital untuk upacara Karumathi. Dibuat dengan HTML, CSS, dan Vanilla JavaScript tanpa framework atau backend.

## Menjalankan website
Buka file `index.html` menggunakan browser modern. Tidak memerlukan proses build.

## Mengubah informasi acara
Buka `script.js` lalu edit object `CONFIG` di bagian paling atas:
- `deceasedName`
- `familyName`
- `eventDate` dengan format YYYY-MM-DD
- `eventTime`
- `venue`
- `address`
- `mapsUrl` (opsional)
- `portraitFile` (default: assets/nenek.jpg)
- `musicFile` (opsional)

Untuk menambahkan foto, buat folder `assets` lalu letakkan foto bernama `nenek.jpg` di dalamnya. Musik latar opsional dan sebaiknya hanya menggunakan audio yang keluarga berhak gunakan.

## Catatan
Arah visual terinspirasi dari elemen desain Tamil India Selatan seperti pola geometris kolam, bentuk lengkung arsitektur, dan lampu minyak tradisional. Website ini merupakan undangan, bukan panduan tata cara ritual; detail upacara perlu dikonfirmasi dengan keluarga dan pemuka agama setempat.
